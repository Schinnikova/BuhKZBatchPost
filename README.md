# Групповое перепроведение документов по расписанию

Расширение для «Бухгалтерии для Казахстана». Добавляет регламентное задание, которое само перепроводит нужные документы за нужный период и отправляет отчет на почту.

---

## Как это работает

1. Регламентное задание `ГП_ПерепроведениеДокументовПоРасписанию` запускается по расписанию.
2. Оно берет настройки из регистра сведений `ГП_ПараметрыРегламентныхЗаданий`.
3. Перепроводит все подходящие документы за указанный период.
4. После завершения сдвигает дату начала на текущий момент (чтобы в следующий раз не перепроводить уже обработанное).
5. Формирует отчет об ошибках и отправляет его на почту получателям из настроек.

Дополнительно: подписка на проведение документов автоматически отодвигает дату начала назад, если проводится документ старше текущей даты начала - чтобы ничего не пропустить.

---

## Настройка параметров

Все параметры хранятся в регистре сведений **«Параметры регламентных заданий (ГП)»** и редактируются через форму настройки обработки.

### Организации
Список организаций, по которым будет выполняться перепроведение. Документы других организаций пропускаются. Если список пустой - ничего не перепроводится.

### Типы документов
Какие именно документы перепроводить. Можно выбрать один или несколько типов из списка проводимых документов конфигурации. Если не выбрано ничего - ничего не перепроводится.

### Дата начала
С какой даты начинать перепроведение. Обновляется автоматически после каждого запуска задания - сдвигается на текущий момент. Также автоматически сдвигается назад, если в системе проводится документ с более ранней датой (работает через подписку на событие проведения).

### Количество месяцев для перепроведения
Ограничение глубины ухода в прошлое при автоматическом сдвиге даты начала. Например, при значении `3` подписка не будет сдвигать дату начала более чем на 3 месяца назад от текущей даты, даже если проводится очень старый документ. По умолчанию `1`.

### Получатели рассылки
Адреса электронной почты, на которые отправляется отчет после каждого запуска задания. Вводятся строкой через `;`. Если поле пустое - письмо не отправляется.

Пример: `ivanov@company.kz;petrov@company.kz`

## Структура расширения

```
CommonModules/
  ГП_ОбщийМодуль          - основная логика: запуск перепроведения, отправка письма, обновление параметров

DataProcessors/
  ГрупповоеПерепроведениеДокументов
    ManagerModule          - процедура перепроведения (модифицирована для поддержки фильтра по типам)
    Forms/Настройка        - форма редактирования параметров регламентного задания

Enums/
  ГП_ПараметрыРегламентныхЗаданий  - ключи параметров регистра

InformationRegisters/
  ГП_ПараметрыРегламентныхЗаданий  - хранилище всех параметров (ключ + значение в ХранилищеЗначений)

ScheduledJobs/
  ГП_ПерепроведениеДокументовПоРасписанию  - регламентное задание

EventSubscriptions/
  ГП_ОбновитьПараметрыРегламентныхЗаданий  - подписка на проведение документов
```
